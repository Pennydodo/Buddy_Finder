Almost there

    
This app needs your own free Firebase project to relay positions between phones. It takes about five minutes, once, and then it is yours forever.

    
    
      
  1. Go to console.firebase.google.com and create a project. Turn Google Analytics off.
    2. 
      
  2. Build → Realtime Database → Create database → pick the region closest to the festival → start in locked mode.
    3. 
      
  3. Build → Authentication → Get started → Sign-in method → enable Anonymous.
    4. 
      
  4. Project settings (gear) → Your apps → Web (</>) → register → copy the firebaseConfig object.
    5. 
      
  5. Paste it into js/config.js, replacing the placeholder.
    6. 
      
  6. Realtime Database → Rules tab → paste the contents of database.rules.json → Publish.
    7. 
    

    
The full walkthrough, with the exact rules, is in README.md.
